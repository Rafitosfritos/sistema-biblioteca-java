 📚 Sistema de Gerenciamento de Biblioteca - Java

Este é um projeto desenvolvido em Java para praticar os conceitos de **Orientação a Objetos (POO)**, manipulação de datas com `LocalDate` e gerenciamento de coleções com `ArrayList`.

 🚀 Funcionalidades

O sistema permite gerenciar o ciclo completo de um livro em uma biblioteca:

- Cadastrar Livro: Salva título, autor e número de páginas.
- Registrar Empréstimo: Calcula automaticamente a data de devolução para 15 dias à frente.
- Registrar Devolução: Libera o livro para novos usuários.
- Ver Biblioteca: Lista todos os livros cadastrados com seus detalhes.
- Busca Inteligente: Pesquisa livros por título ou autor, informando se o exemplar está disponível ou qual a data prevista de retorno.
